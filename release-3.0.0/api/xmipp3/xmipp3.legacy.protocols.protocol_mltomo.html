Bases: ProtClassify3D

Align and classify 3D images with missing data regions in Fourier space, e.g. subtomograms or RCT reconstructions, by a 3D multi-reference refinement based on a maximum-likelihood (ML) target function.

See http://xmipp.cnb.csic.es/twiki/bin/view/Xmipp/Ml_tomo_v31 for further documentation
